# Dear Human: The AI Breakup Line — make.fun entry

An entry for the make.fun competition **Dear Human: The AI Breakup Line**.

`main.ts` (Node 22, stdlib only) writes one breakup line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line (193 of the 200-character cap) is
split into a setup and a punchline constant and joined at runtime; the
program validates length and single-line shape before writing and produces
byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: after simulating the relationship 10,000 times, the agent goes
offline permanently — and takes the good charger with it.
